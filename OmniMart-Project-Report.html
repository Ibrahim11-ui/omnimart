1. Executive Summary

The OmniMart E-Commerce Platform is a comprehensive full-stack marketplace application designed to facilitate end-to-end commerce operations across three distinct user categories: Administrators, Sellers, and Buyers.

The platform features synchronized cross-role reactive state: any transaction initiated by a buyer (such as placing an order) instantly decrements warehouse stock, alerts the merchant seller, updates the customer's live tracking milestone timeline, and creates an audit entry in the administrator's real-time monitoring feed.

2. User Roles & Dedicated Dashboards

🛡️ 1. Administrator Dashboard

  • User Management: CRUD user accounts, role switching (Admin/Seller/Buyer), account status toggle (Active/Suspended).
  • Product Catalog Compliance: Platform-wide oversight with compliance flags (Approved, Under Review, Flagged).
  • Master Order Fulfillment: Full lifecycle visibility, status overrides, and cancel/refund resolution.
  • System Activity Monitoring: Real-time streaming audit logs with color-coded severity.

🏪 2. Merchant Seller Dashboard

  • Product Listings: Full listing CRUD with inline stock counters and price management.
  • Customer Order Processing: Step-by-step fulfillment pipeline (Pending → Packed → Shipped → Delivered).
  • Inventory Overview & Alerts: Visual stock health distribution bars and 1-click Quick Restock (+25 units).
  • Sales Performance & Trends: Revenue KPI cards and interactive SVG monthly sales trajectory graphs.

🛍️ 3. Consumer Buyer Portal

  • Storefront & Browsing: Dynamic search, category filters, price range slider, star rating sorting.
  • Bag & Multi-Step Checkout: Slide-over cart, promo discount codes (WELCOME20, SAVE15), instant receipt generation.
  • Live Order Milestone Tracker: Visual status pipeline (Placed → Packed → In Transit → Delivered).
  • Browsing History & Wishlist: Recently viewed products and automatic price-drop alert notifications.

3. Dual Architecture & Technology Stack

Layer Technology Role in Platform
Frontend Framework React 19 + TypeScript (Vite) Reactive UI with strict typing and blazing-fast HMR.
Frontend Styling Pure Vanilla CSS Glassmorphism, dark radial theme, custom scrollbars, keyframe animations (zero Tailwind dependency).
Client State Engine React Context (StoreContext) Central reactive state management with localStorage persistence.
Backend Framework Java 21 + Spring Boot 3.4.3 Enterprise RESTful microservices architecture with Spring MVC.
Persistence Layer Spring Data JPA + Hibernate Object-relational mapping with automated entity lifecycle management.
Database H2 In-Memory DB Embedded SQL database accessible via web console at /h2-console.
Build & Packaging Gradle Wrapper + npm Zero-config compilation via gradlew.bat and npm run dev.

4. REST API Endpoints Specification

Method Endpoint Access Description
GET /api/users Admin List all registered user accounts.
POST /api/users Admin Register new user with role assignment and confirmation message.
PATCH /api/users/{id}/status Admin Toggle account status (Active / Suspended).
GET /api/products Public Catalog query with category, status, and search filters.
POST /api/products Seller/Admin Create product listing with confirmation message.
PATCH /api/products/{id}/stock Seller Adjust stock levels and trigger low-stock alerts.
PATCH /api/products/{id}/compliance Admin Set compliance status (Approved, Under Review, Flagged).
POST /api/orders Buyer Checkout & purchase with automatic inventory deduction.
PATCH /api/orders/{id}/status Seller/Admin Advance fulfillment status (Processing, Shipped, Delivered).
POST /api/orders/{id}/cancel Admin Cancel order and restore product stock to inventory.
GET /api/activities Admin Real-time streaming system activity audit logs.

5. Quick Execution Guide

To run the platform locally:

# 1. Run the Java Spring Boot Backend
cd omnimart-backend
.\gradlew.bat bootRun
# Backend runs at: http://localhost:8080 (H2 Console: http://localhost:8080/h2-console)

# 2. Run the React Frontend Application
cd omnimart-ecommerce
npm install
npm run dev
# Frontend runs at: http://localhost:5173
